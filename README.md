# Корзина интернет-магазина на Dart 3

Практика на 1 час 10 минут: модели, валидация, коллекции, nullable-значение и полиморфизм через интерфейс.

## Запуск

Нужен Dart 3 без дополнительных пакетов.

```bash
dart run task.dart
```

Можно также скопировать `task.dart` в DartPad.

## Что реализовать

Заполните все `TODO` в `task.dart`:

1. Провалидируйте `Product` и `CartLine`.
2. Реализуйте `lineTotalKopecks`.
3. Реализуйте `PercentDiscount` и `FixedDiscount` через общий `Discount`.
4. Объедините одинаковые товары в `mergeLines`, сохранив порядок первого появления.
5. Реализуйте subtotal и итоговую стоимость корзины.
6. Не изменяйте входной список; наружу отдавайте список только для чтения.

Деньги хранятся только как `int` в копейках. Итог после скидки не может быть отрицательным.

Готовое решение выводит десять строк `OK` и завершает работу сообщением:

```text
Все проверки пройдены
```

## Оценка

- **0 баллов:** программа не запускается, расчёт корзины отсутствует либо студент не может объяснить решение.
- **1 балл:** программа запускается и обычный subtotal работает, но не выполнен хотя бы один обязательный сценарий: валидация, объединение, одна из скидок, ограничение нулём или неизменность данных.
- **2 балла:** проходят все проверки, используются целые копейки, обе скидки реализуют общий контракт, входные данные не меняются, студент объясняет `implements`, nullable-скидку и создание новой коллекции.

Дополнительное задание не повышает оценку выше 2: реализовать форматирование копеек в строки вида `583,20 ₽` и добавить проверки.
